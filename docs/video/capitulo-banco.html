1. DBeaver: as duas conexões

O Top Gerente é a fonte oficial do comercial (somente leitura). O app grava no banco 3e_operacoes.

topgerente: pedidos, itens, clientes e vendedores do ERP. O app nunca escreve aqui; o conector local faz SELECT parametrizado.
3e_operacoes: snapshot do pedido + produção, ocorrências, entregas, remessas, usuários e auditoria. É aqui que o app grava.
● verde: conexão ativa● cinza: disponívelFonte: janela do DBeaver

2. Mapa das tabelas do app

O caminho do dado acompanha a operação: pedido → item → atividade → execução/ocorrência; a entrega e a previsão ficam no item.

pedidos→pedidos_itens→atividades→execucoes ·ocorrencias·entregas·remessas_programadas·logs_auditoria
A previsão de entrega do item fica em pedidos_itens.deadlineAt. As remessas são datas previstas em remessas_programadas; as entregas realizadas ficam em entregas.

6. Histórico de prazos (auditoria)

Toda alteração de prazo grava uma linha em logs_auditoria com antes, depois, usuário e data/hora.

SELECT beforeJson, afterJson, createdAt
FROM logs_auditoria
WHERE action = 'DEADLINE_CHANGED'
ORDER BY createdAt DESC LIMIT 5;
QuandoAntesDepois
27/10/2026, 23:3313/12/202606/12/2026

A alteração acima foi feita pelo Gerente na demonstração: o prazo foi para 13/12/2026 e voltou para 06/12/2026. As duas linhas permanecem para auditoria; o valor atual do item é o último “depois”.
